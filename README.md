# Story and Email Generator

A Google Colab notebook that uses the Gemini API to generate short stories and emails from user input.

- **Story generator:** Enter a topic, genre, and approximate word count.
- **Email generator:** Enter the email details, recipient, tone, and approximate word count.

## How to run

1. Open `Story_and_Email_Generator_(1).ipynb` in Google Colab.
2. Add your Gemini API key to Colab Secrets as `GEMINI_API`.
3. Run the cells in order and follow the prompts.

Built with Python and the Google Gen AI SDK. Do not upload your API key to GitHub.
